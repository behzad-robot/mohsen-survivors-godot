## Update procedure

1. At the start of a development turn, read this file and the task instructions; resume from the current focus and unchecked items. Inspect files before assuming a previous checkbox reflects the current code.
2. When a work item is fully written, mark its **Code written** box `[x]`. Leave **Designer verified** unchecked and provide the designer with short manual test steps.
3. After the designer reports a successful test, mark **Designer verified** `[x]`. If the test fails, record the symptom and move the item back to active work; do not erase the test feedback.
4. Update **Last updated**, **Current focus**, **Next recommended work**, and **Known blocker**. Add paths and decisions to the log below, especially provisional balance values and deviations from the PRD.
5. On a new developer task, append its work items here before or while implementing them. Keep completed items for history. The art backlog remains in `art-requirements.md`.
